# Premium Infographic Reference

- 기준 이미지 파일: `premium_infographic_reference.png`
- 용도: 프리미엄 인포그래픽 생성 기능의 단일 디자인 레퍼런스
- 적용 기준:
  - 상단 히어로 헤더 구조
  - 적용분야/제품 풀컬러 카드 3개 구성
  - 시장현황 막대그래프 + KPI 카드 2개 구성
  - 기술개요/핵심 차별성 row 카드 구성
  - 대표도면 + 기술 경쟁력 비교 구조
  - 지식재산권 표 및 하단 문의처 바 스타일
- 주의:
  - 대학 로고, PIUM 로고, QR, 대표도면, 기술 내용은 입력 데이터 기준으로 유지
  - 레퍼런스 이미지는 스타일 기준이며, 자동 생성 시 텍스트/로고는 현재 입력값으로 대체
