# Premium Reference Template Mode

`premium_infographic_reference.png` 는 프리미엄 인포그래픽의 디자인 방향을 잡기 위한 기준 레퍼런스입니다.

## 최신 동작 방식
1. `gpt-image-2` 는 레퍼런스를 참고하여 **텍스트 없는 프리미엄 배경/카드 템플릿**만 생성합니다.
2. 아래 요소는 모델이 그리지 않고, 코드가 정확히 합성합니다.
   - 대학 로고
   - PIUM 로고
   - QR 코드
   - 대표도면
   - 제목 / 소속 / 서브카피
   - 적용분야 텍스트
   - 시장현황 그래프와 KPI 수치
   - 기술개요 / 핵심 차별성 / 기술 경쟁력 텍스트
   - 지식재산권 표
   - 문의처
3. 이 방식은 QR, 특허번호, 이메일 등 정확성이 필요한 요소의 변형을 줄이기 위한 하이브리드 방식입니다.

## 모델 라우팅
- 적용분야/제품 보조 이미지: `gpt-image-1-mini`
- 프리미엄 배경/카드 템플릿: `gpt-image-2`
- 시장현황 그래프: 코드 기반 렌더링
