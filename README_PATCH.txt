PIUMTECH 라인 아이콘 패치

적용제품/제품 아이콘을 아래 스타일로 변경합니다.
- 단순 2색 라인 아이콘
- 연한 원형 배지 배경
- 흰 바깥 배경
- card / panel / monitor / mockup / pedestal / underline 금지

함께 포함되는 변경
- 텍스트 모델: gpt-5.6-luna
- 일반 이미지: gpt-image-2.5-flare
- 프리미엄 이미지: gpt-image-2.5-sunburst
- store=False
- prompt_cache_options={"mode":"explicit"}
- reasoning 기본 none

사용법
1. 현재 app.py를 이 폴더에 넣기
2. APPLY_PATCH.cmd 실행
3. 생성된 app_patched.py를 app.py로 이름 변경
4. 서버/깃허브에 업로드

권장
- 가능하면 기존에 패치된 파일이 아니라 원본 app.py 기준으로 적용
- 업로드 후 앱 재시작
- 브라우저 새로고침 및 캐시 무효화 후 재생성 확인
